# 设计规范

生成新的数学教学课件时遵循的约定。目标是：与既有课件风格一致，公式结构正确，两个引擎都能完整显示。

---

## 一、文件与页序

一课一份，文件名 `NN课程名.pptx`（`NN` 为两位数课次）。页序固定：

| 页 | 内容 | 说明 |
|---|---|---|
| 1 | 封面 | 课次、课题 |
| 2 | 学习目标 | 3–4 条，可检验 |
| 3 | 情境导入 | 一个具体问题，引出本课主概念 |
| 4 | 概念/定义 | 严格表述 + 一句人话解释 |
| 5–N | 例题 | 一例一页或两例一页，每例含"识别 → 求导 → 回代"三步 |
| N+1… | 随堂练习 | 对应练习册的小节，题号一致 |
| 末 | 小结 | 思维导图式要点 |
| 末+1 | 课后作业 | 明确题号 |

练习页规则：

- **题号必须与练习册一致**（`练习册 3.7：填空题（1）`）。
- 整题略讲时，页面上要写明原因：`第 9、12、13 题与第 7 题相同（练习册重复印刷），略。`
- 一道填空题一行，答案用独立形状放在 `（　）` 空位或紧随题干。

## 二、公式要求（硬性）

全部使用真 OMML，不得用文字近似。

| 内容 | 正确 | 错误 |
|---|---|---|
| 分数 | `m:f`（`m:type="bar"`） | `1/x`、`x²/2` 斜杠平写 |
| 上标 | `m:sSup` | `x^2`、`x3/2`、`x½`、Unicode `x²` |
| 下标 | `m:sSub` | `x_n` |
| 极限 | `m:limLow`（条件在 lim 正下方） | 文字 `lim`、`m:sSub` 加 lim |
| 根式 | `m:rad` | `sqrt(x)`、`√x` 直接打字符 |
| 函数 | `m:func`（**必须有自变量**） | 空的 `m:func`（渲染成方框） |
| 括号组 | `m:d`（可配 `begChr`/`endChr`） | 裸括号字符 |
| 分段 | `m:eqArr` + `m:d` 配 `begChr="{"` | 多行文本框硬凑 |

**公式容器**：整段内联公式用 `<a14:m><m:oMath>…</m:oMath></a14:m>` 直接放在 `a:p` 下。独立成行的公式也用 `a14:m > m:oMath`，不要嵌 `m:oMathPara`，更不要在 `oMathPara` 里再套 `a14:m`（详见缺陷目录 M-BADNEST）。

**`oMath` 内部只能用 `m:r` + `m:t`**，属性块是 `a:rPr`：
```xml
<m:r>
  <a:rPr lang="zh-CN" sz="2400" i="1" dirty="0">
    <a:solidFill><a:srgbClr val="1F1F1F"/></a:solidFill>
    <a:latin typeface="Cambria Math"/>
  </a:rPr>
  <m:t>x</m:t>
</m:r>
```
写成 `a:r` 会让 PowerPoint 拒绝打开文件。

## 三、形状命名

沿用既有课的命名，便于脚本与动画定位：

| 前缀 | 用途 | 示例 |
|---|---|---|
| `TextBox N` | 普通文字 | `TextBox 7` |
| `header` / `footer` | 页眉页脚组 | — |
| `anim-NN-k` | 第 NN 页第 k 个揭示块 | `anim-04-1` |
| `ansXX-k` / `ans-sXX-k` | 第 XX 页第 k 个答案 | `ans10-1` |
| `q-sXX-kk` | 第 XX 页第 kk 题的题干 | `q-s21-11` |
| `v-q-sXX-kk-m` | 该题第 m 个空的答案 | `v-q-s21-11-1` |
| `def` / `img1` / `img2` | 定义卡片、图片卡片组 | — |

**题号与答案用同一套编号**，脚本才能配对着。

---

## 四、动画

- 答案、揭示块一律用进入动画（`presetClass="entr"`），初始 `hidden="1"`。
- 每页动画顺序：题干先出，答案随后。
- 若采用"答案盖住题干"的揭示设计，两个形状**位置完全一致**，答案文本包含题干完整前缀。这是允许的，但要保证答案形状最后出现，且放映时不会同时看到两份。
- 每个 `hidden="1"` 的形状必须至少被一个 `p:spTgt` 引用，否则永远不显示。

---

## 五、版面

- 画布 13.333 × 7.5 英寸（16:9）。所有形状必须落在画布内，`x + w ≤ 13.33`、`y + h ≤ 7.5`。
- 答案形状放在 `（　）` 内部或紧接题干之后，间距 0.1–0.2 英寸。
- 填空答案要**用 PowerPoint 实测的 `（` 字符横坐标**定位，不要按形状框估。
- `wrap="none"` + `spAutoFit` 的文本框宽度不可信，按文字实际宽度算位。
- 图片卡片组的 `a:ext` 要以图片实际范围为准，不要留出比页面还大的空白框。

---

## 六、自检清单

交付前逐条过：

- [ ] `verify_integrity.py` 无 XML 解析错误、无孤儿动画目标
- [ ] 每页 `<m:oMath` 计数不低于模板基线
- [ ] 无 `m:oMathPara` 内嵌 `a14:m`
- [ ] 无 Fallback 为空的 `mc:AlternateContent`（或全部展开）
- [ ] 无空的 `m:func`（`sin` 没自变量）
- [ ] 所有 `lim` 用 `m:limLow`
- [ ] 无 `baseline="30000"` 的独立指数 run
- [ ] 无画布外形状
- [ ] 每个 `hidden="1"` 形状都有动画指向
- [ ] PowerPoint 打开无修复提示
- [ ] WPS 打开后逐页检查公式是否完整（**必须做**）
- [ ] 练习页题号与练习册一致，或已注明跳过原因

## 七、常见生成失误

| 失误 | 后果 | 规避 |
|---|---|---|
| 用 `a:r` 写公式内文本 | PowerPoint 打不开文件 | 一律 `m:r` + `m:t` |
| 把整个形状包进 `mc:AlternateContent` 且 Fallback 留空 | WPS 整块空白 | 直接输出 `p:sp` |
| 生成 `m:oMathPara` 再套 `a14:m` | WPS 整段不显示 | 用 `a14:m > oMath` |
| 指数写成 `baseline` 独立 run | 换环境掉回基线 | 用 `m:sSup` |
| 答案坐标按形状框估算 | 答案压字/脱节 | 用 `BoundLeft/BoundWidth` 实测 |
| 两栏题目按 y 排序配对答案 | 误报缺答案 | 先按 x 分栏 |
| 用 `a14:m` 计数做完整性断言 | 掩盖丢公式 | 用 `<m:oMath[ >]` |
